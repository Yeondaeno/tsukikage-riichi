# 조작과 설정

히나가 플레이어이며 아카네·시즈쿠·코하루가 CPU다. 1국 연습, 동풍전, 반장전과 적도라 선택을 유지했다.

- 손패 첫 클릭/터치: 선택. 선택한 **같은 실물 패**를 다시 누르면 버림. 재클릭 시간 제한이 없다.
- 같은 종류의 다른 패, 적5와 일반5를 서로 누르면 선택만 바뀐다.
- 패를 드래그하여 표시된 버림 영역에 놓으면 버림. 9px 이전 이동은 클릭으로 취급한다. 영역 밖, 포인터 취소, 창 포커스 이탈, 회전/리사이즈, 모달, 차례 변화에서는 드래그가 취소된다.
- Enter/버리기 버튼: 선택한 패만 버림. 선택 없이 리치 쯔모패를 자동 추정하지 않는다.
- 방향키: 선택 이동. R: 리치 모드. W: 가능한 론/쯔모. Esc: 선택·울기 취소/패스 또는 연출 건너뛰기. P: 일시정지.
- 리치 후 자동 버리기는 기본 꺼짐이며 설정에서 사용자가 직접 켤 수 있다. 화료/깡 선택이 있을 때는 기다린다.

리치 선언패는 각 좌석의 버림패 방향에 대해 90도로 눕힌다. 상대에게 가져간 경우에도 선언패 위치는 흐리게 남는다. 리치 성립 후 1,000점과 중앙 공탁금이 반영된다. 선언패 론에는 공탁금이 없다.

좌상단 왕패는 공개된 도라 표시패만 보여 준다. 우라도라는 결과에서만 공개한다. 실제 도라 안내, 보조 숫자/한글, 추천 버림패, 같은 공개 패 강조, 대사, 대사 빈도, 연출, 도라 반짝임은 독립 설정이다. 공개 버림패는 마우스 올리기·키보드 초점·터치 길게 누르기로 확대한다.

가이드 수준은 끄기 / 요청할 때 / 자동 설명 / 멈춰서 배우기다. 튜토리얼은 CPU 타이머를 멈추고 같은 상태에서 이어간다. 대기패의 미공개 장수는 상대 손패와 왕패를 포함하므로 실제 패산 잔량이 아니다. 추천은 공개 정보와 패 효율의 참고값이며 정답을 보장하지 않는다.

효과음은 첫 사용자 입력 이후 재생하며 효과음과 음성 음량을 따로 저장한다. **녹음 음성은 이번 빌드에 없다.** 음성 슬롯은 manifest의 null이며 자동 TTS나 가짜 음성을 재생하지 않는다.

가로 모바일에서는 왕패·점수·손패·울기/화료 버튼을 대국 화면에 유지한다. 세로 화면은 회전 권유를 표시하며 설정 접근을 막지 않는다. 결과/규칙/설정 모달 내부는 내용이 길면 스크롤할 수 있다.
