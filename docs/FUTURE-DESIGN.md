# 설계만 제공하는 향후 기능

아래 기능은 이번 제품 화면이나 저장된 전적 서비스에 구현하지 않았다.

## 대전 모드 분리

현재 실행은 로컬 1인+CPU3명이다. 추후 Practice / CharacterMatch / FreeTable 정책을 세션 옵션으로 분리하고 모든 모드가 같은 규칙 엔진을 사용한다. 온라인 전송, 서버 권한, 매칭, 계정은 별도 검토가 필요하다. 현재 mode=single/east/half는 국 진행 길이 옵션이며 온라인 모드가 아니다.

## 리플레이·패보

엔진 명령을 입력으로, seq가 있는 사건을 출력으로 기록한다. 미래 ReplaySession은 기록된 seed, rulesVersion, 처음 상태, 명령을 순서대로 적용하고 매 사건 이후 타일·점수 보존 및 stateHash를 비교한다. 렌더러/연출은 이벤트 소비자이며 엔진 정산을 호출하지 않는다. seek는 체크포인트 복원 후 재연산한다.

확정/취소된 리치, 가깡 제안/창깡, 더블 론의 화료자 순서, 유국, 공탁금 귀속을 구별한다. 뷰어는 결과 공개가 허용될 때만 전 손패를 표시한다. 진행 중 공개용 패보에서 미공개 패산/CPU 손패를 내보내지 않는다. 현재 자동 저장은 재개 스냅샷이며 검증된 리플레이 포맷으로 간주하지 않는다.

## 전적·통계

종료된 세션만 matchId로 한 번 적재한다. 순위, 득점, 화료/방총/리치/울기 수, 규칙 버전과 CPU 성향을 기록한다. 중도 종료는 완료 전적에 섞지 않는다. 분모와 모드별 집계를 명시한다. 사용자 삭제/내보내기와 저장 불가 처리를 설계한다. 이번 빌드에는 통계 대시보드, 승률, 수집 보상, 재생 버튼이 없다.

## 현재 경계

src/engine.js: 패/역/부/정산/국 진행/이벤트와 저장 가능한 게임 난수.
src/policy.js: 성향 가중치와 후보 선택. 입력은 자신의 패 효율과 공개 위험도이며 난이도는 별도 인자다.
src/input.js: 실물 패 ID, 이동 임계값, 드롭 검증, 취소와 합성 클릭 방어.
src/visuals.js 및 scenes.css: 공개 왕패·점수·순위·단계별 화료. 포인트를 변경하지 않는다.
src/characters.js: 소재 경로/표정/대사/오디오. 음성 슬롯은 미제작 상태.
src/app.js: 각 경계 조립, 공개/자기 패 렌더링, 모달·도우미·저장 UI. 온라인 어댑터는 없다.

다음 단계 테스트: 동일 명령 스트림 재생의 상태 해시, 규칙 버전 불일치 거부, 시킹 전후 무작위 상태 일치, 여러 화료자 정산 중복 수신, 완료 전적 중복 적재, 중단된 대국 제외, 공개용 사건의 은닉 정보 검사.
