# 하우스 룰과 구현 한계

현재 규칙 엔진의 실제 동작을 적었습니다. 공식 대회 규정 전체와 일치한다고 주장하지 않습니다.

## 구현한 룰

- 4인, 136개 물리 패·34종류, 선택 가능한 적도라 3장. 시작 25,000점.
- 1국 연습, 동풍전, 반장전. 친 화료·친 텐파이 연장, 본장·공탁금·친 이동·국 진행·음수 타가 종료.
- 리치·더블리치·일발, 치·퐁·대명깡·암깡·가깡, 영상패·깡도라·우라도라, 쯔모·론·후리텐.
- 치는 왼쪽 상대만, 치 직후 금지 버림패 검증. 리치는 멘젠·텐파이·1,000점 이상·남은 패 4장 이상에서 가능.
- 리치 선언패가 론을 통과한 뒤 1,000점을 공탁합니다. 가져간 선언패는 회전 표시를 유지합니다.
- 역 없는 화료와 도라만 있는 화료는 불가. 쿠이탕 허용, 열린 핑후 불가.
- 일반형·치또이츠·국사무쌍의 샹텐·대기·역·부·제한 점수 계산. 만관 2,000/하네만 3,000/배만 4,000/삼배만 6,000/역만 8,000 기본점. 13판 이상 헤아림 역만.
- 복수 역만 합산과 설정된 더블 역만. 가깡 창깡, 암깡의 국사무쌍 창깡. 리치 후 암깡은 대기와 분해가 유지되는 경우만 허용.
- 동시 론 2명은 둘 다 화료하고 공탁은 가장 가까운 승자가 받습니다. 3명 론은 삼가화 도중 유국.
- 유국 텐파이 정산 총 3,000점. 구종구패·사풍연타·사가리치·여러 사람의 사개깡 도중 유국.
- 마지막 친이 연장 조건을 만족하고 30,000점 이상 1위이면 종료. 서입·북입 연장은 하지 않습니다. 동점은 시작 좌석 순서, 종료 시 남은 공탁은 최종 1위에게 줍니다.

## 미구현 또는 검증 범위 밖

- 유국 만관, 책임지불(파오), 우마·오카, 키리아게 만관, 대회별 세부 옵션은 구현하지 않았습니다.
- CPU는 효율·도라 가치·공개 위험·호출·리치의 가중치 휴리스틱입니다. 최적 전략이나 강함을 보장하지 않습니다. 상대 손패·패산 내부를 판단에 쓰지 않는 검사는 통과했습니다.
- 미래 기능 문서의 신규 모드 분리·리플레이·패보·전적 통계는 실행 기능이 아닙니다.
- 정식 음성·온라인 매칭·계정·결제·수집 기능은 없습니다.
- 터치는 Chromium 에뮬레이션으로 검사했습니다. 실물 모바일의 OS 제스처·메모리 압박·Safari/WebKit·실제 스피커 출력은 검증하지 않았습니다.
