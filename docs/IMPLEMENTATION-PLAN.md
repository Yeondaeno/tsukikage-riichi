# 월영마작 v3 구현 범위와 진행 순서

기준 문서: 제공된 START-HERE.md와 전체 개선 프롬프트. baseline HTML과 소스 ZIP은 수정하지 않고 별도 작업 폴더에 해제했다.

1. 기존 엔진과 화면 흐름을 읽고 원본 단위 검사 39개 및 자동 대국 100회 실행.
2. 같은 실물 패의 재클릭, Pointer Events 드래그, 취소, 중복 입력 방지. 기본 리치 자동 버림 끄기.
3. 리치 선언/성립 이벤트와 공탁금 정산 경계, 승리/유국 정산 중복 방지, 저장 가능한 시드 난수.
4. 실제 네 캐릭터 기본 이미지, 7개 표정, 승리 컷인, 특별 포즈, 대사와 효과음 제작/연결.
5. PC와 가로 모바일 독립 배치, 읽을 수 있는 SVG 패, 가로 리치패, 공개 패 확대, 좌상단 왕패.
6. 규칙 엔진 결과를 사용하는 단계별 화료와 순위 연출. 다중 론/건너뛰기/미리보기 검수.
7. 공개 정보만 사용하는 CPU 성향, 독립 보기 설정, 네 가이드 수준, 저장 형식 이행.
8. 실제 브라우저 조작, 시뮬레이션, 예외 검사, 자료와 소스/정적 빌드 묶음 제공.

실서비스 배포, 온라인/계정/결제/수집, 대전 모드 분리·리플레이·패보·전적 통계의 제품 구현은 범위에 넣지 않는다. 후자의 확장 설계만 제공한다.
