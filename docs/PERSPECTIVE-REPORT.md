# v3.1 입체 마작탁 구현·검수

2026-10-02, Windows의 격리 Chromium과 browser-harness로 검수했다. 모바일 크기와 터치는 에뮬레이션이다.

## 실제 구현

기존 실제 대국 요소를 단일 tablePlane 안에 배치하고 CSS perspective/rotateX와 translateZ를 적용했다. 녹색 펠트·다층 목재 프레임·아이보리 패 상판·금색 비공개 패 뒷면과 측면 그림자를 사용한다. 실제 SVG 패와 제작된 캐릭터 4명·표정·컷인·효과음을 그대로 연결한다. 참고 게임의 화면 이미지를 탁이나 패 대신 붙이지 않았다. WebGL이나 외부 라이브러리는 추가하지 않았다.

손패, 드롭 영역, 캐릭터 좌석, 왕패 HUD는 변형 면 밖의 평면 DOM이다. 기존 입력 모듈의 화면 좌표와 유효 사각형 판정을 유지한다. 첫 클릭은 선택이고 같은 물리 패의 재클릭·재터치는 시간 제한 없이 버린다. 원클릭 버리기를 추가하지 않았다. 드래그 취소 이후의 기존 450ms 합성 클릭 억제는 중복 입력 방지이며 재클릭 시간 제한이 아니다.

PC에서는 버림패가 중앙판의 네 방향에서 바깥으로 늘어난다. 높이가 짧은 휴대폰 가로 화면은 기울기를 줄이고 이름이 있는 네 열로 정리한다. 공개 패 가독성과 가림 방지를 우선한 반응형 배치다. CPU 공개 부로는 숨긴 패보다 큰 크기를 유지한다. 규칙·CPU·점수 정산·입력 JavaScript는 변경하지 않았다.

## 실행한 검사

| 검사 | 실제 결과 |
|---|---|
| 규칙 단위 검사 | 39/39 통과 |
| v3 상태·CPU·중복 정산 검사 | 7/7 통과 |
| 자동 대국 | 100국, 69화료·28유국·3도중 유국, 136장 보존 |
| 대전 완주 | 동풍전 3회·반장전 3회, 총 46국 |
| 신규 입체 탁 브라우저 검사 | 45/45 통과 |
| 기존 브라우저 회귀 검사 | 91/91 통과 |

화면 크기는 1920×1080, 1366×768, 844×390, 740×360이다. 모든 크기에서 페이지·손패가 화면에 들어오고, 20/16/16/16장 긴 국면의 공개 패 68장과 리치 선언패가 잘리지 않으며, 패 중심을 캐릭터·중앙판·드롭 영역·CPU 패·풍 표시 등이 가리지 않는지 확인했다. 공개 패의 표시 영역 짧은 변은 최소 12px 기준을 통과했다. 색과 숫자 보조 표기, 공개 패 확대 기능도 유지한다.

실제 포인터 입력으로 최초 클릭 선택, 600ms 뒤 같은 물리 패 재클릭, 유효 드롭 한 번, 영역 밖 취소, 포인터 취소, 중복 release 무효, 실제 터치 선택/재터치를 검사했다. 기존 회귀 검사는 리치 공탁·선언패 론·깡·후리텐·다중 화료·연출 단계·건너뛰기 중복 정산·저장·에러 대응·소재 로딩을 포함한다.

첫 초안에서는 기존 CSS의 top/left가 새 bottom/right와 동시에 적용되어 패와 좌석이 겹쳤다. 좌표를 명시적으로 초기화하고, 버림패가 중앙판에서 바깥으로 성장하도록 수정했다. 휴대폰의 큰 기울기로 패가 작아지는 문제, 드롭 영역과 풍 표시의 가림, 공개 부로의 지나친 축소도 수정했다. 브라우저를 통해 현재 빌드를 다시 검사한 통과 결과를 위 표에 기록했다.

증거: tests/results/perspective/perspective-checks.json, 네 화면의 geometry.json와 PNG, tests/results/browser-*.json. tests/perspective_checks.py는 기존 브라우저 도구의 공통 헬퍼를 사용한다. 정적 Python 문법 검사만으로 내부 JavaScript가 검증되지 않으므로 실제 브라우저 실행을 완료했다.

최종 화면 검토에서 재질 색상을 공통 설정으로 정리했다. 실제 62개 의미 토큰을 DESIGN.md와 CSS에 일치시키고, 같은 진행 중 대국을 동작이 멈춘 동일 조건에서 이전 직접 색상값과 비교했다. 1366×768의 픽셀 차이는 0이었다. palette-equivalence.json과 전후 PNG에 기록했고, 정리 후 입체 검사 45개를 다시 통과했다. 소재 검수 시 목록에서 패·탁·제작 경위가 삭제되던 기존 검사 스크립트도 병합 저장으로 수정했다.

## 서브에이전트와 통합

입체 탁 CSS 제작, 회귀 검사 작성, 변형 좌표 영향 검토를 독립적으로 맡겼다. 메인 작업자는 변경을 통합하고 실제 브라우저에서 발견한 문제와 검사 스크립트를 수정했다. 최종 화면과 코드에 대한 독립 검토 결과는 같은 폴더의 리뷰 기록에 포함한다. 서브에이전트의 정적 검토나 미실행 검사를 실제 플레이 통과로 계산하지 않았다.

## 재현

```text
python build.py --output dist/index.html
npm test
python -m http.server 8765 --directory dist --bind 127.0.0.1
BU_CDP_URL=http://127.0.0.1:9331 browser-harness < tests/perspective_checks.py
```

마지막 명령은 설치된 browser-harness와 별도의 검수 Chromium CDP 연결을 사용한다. PowerShell에서는 환경 변수를 설정하고 Get-Content tests/perspective_checks.py | browser-harness로 입력할 수 있다. 일반 플레이에는 이 도구나 서버가 필요하지 않다. 배포 ZIP의 index.html과 assets를 함께 유지한다.

## 검증 범위와 미완료 소재

실물 iPhone/Android, Safari/WebKit, 다양한 모바일 GPU·배터리 성능은 검증하지 않았다. 이 보고서는 Lighthouse 점수나 실제 사용자 접근성 인증을 주장하지 않는다. 캐릭터 음성은 기존과 같이 미제작이다. 이번 변경은 기존 실제 소재를 재사용하며 새 캐릭터 제작으로 보고하지 않는다.

대전 모드 분리·리플레이·패보·전적 통계는 FUTURE-DESIGN.md의 설계만 유지한다. 온라인 매칭·계정·결제·수집 시스템을 구현하지 않았다. 기존 v3의 하우스 룰과 제한은 HOUSE-RULES.md를 따른다.
