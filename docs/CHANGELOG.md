# v3 변경 내역

## v3.2 · Three.js 공개 탁

- Three.js `0.186.1`으로 목재·펠트·조명·카메라를 갖춘 WebGL2 탁을 추가했습니다. 공개 버림패·공개 부로는 37개 로컬 SVG를 `CanvasTexture`로 표시하고, CPU 손패는 뒷면 개수만 표시합니다.
- 손패와 버림 조작은 DOM에 남겨 시간 제한 없는 재클릭, 터치, 드래그와 취소 동작을 유지했습니다. WebGL2·Three.js 누락 또는 컨텍스트 손실에는 CSS 탁으로 전환하고, 컨텍스트 복구 후 같은 대국을 다시 표시합니다.
- 짧고 넓은 스테이지에는 compact 배치를 적용했습니다. 휴대폰 가로 844×390·740×360 터치/크기 에뮬레이션과 중앙 카운터 보드 포함 검사를 포함해 Three.js 브라우저 검사 58/58이 통과했습니다. 자세한 범위는 [Three.js 보고서](THREE-REPORT.md)에 있습니다.
- 실제 엔진의 공개 치·퐁·대명깡 면, 암깡의 안쪽 두 면, 적5/아카 전환, 미드나이트·아이보리·제이드 스킨 전환도 3D 공개 패과 게임 상태 보존 기준으로 확인했습니다.
- 기존 브라우저 회귀 91/91, 규칙·v3 엔진 46/46, 자동 100국(화료 69·유국 28·도중 유국 3), 동풍전·반장전 6회 46국이 현재 증적에서 통과했습니다.
- 현재 공개 GitHub Pages는 v3.1입니다. v3.2 공개 배포는 부모 저장소가 main을 갱신할 때까지 대기합니다.

## v3.1 · 입체 마작탁

- 사용자 참고 화면의 공간 구성을 바탕으로 실제 탁 요소에 CSS 3D 원근, 목재 프레임, 녹색 펠트와 패 측면 깊이를 적용했습니다.
- 캐릭터·왕패·손패·버림 영역은 평면으로 유지합니다. 선택한 물리 패의 재클릭·재터치와 드래그 입력은 기존 공통 모듈을 사용합니다.
- 참고 게임의 캐릭터나 워터마크를 사용하지 않고 기존 월영마작의 실제 제작 소재를 재사용했습니다. 새 음성은 제작하지 않았습니다.
- PC와 휴대폰 가로 화면의 긴 국면·리치 선언패·부로·조작·화료 연출을 실제 브라우저로 확인한 범위는 PERSPECTIVE-REPORT.md에 기록합니다.

## v3 원본 개선

원본 v2 HTML·소스 ZIP과 제공 패키지는 수정하지 않고 별도 작업 사본에서 개선했습니다.

- 선택한 물리 패의 재클릭·재터치와 유효 영역 드래그를 공통 조작으로 연결했습니다. 시간 제한 없는 재클릭, 다른 동종 패의 선택 변경, 적5와 보통5 구별, 영역 밖·포인터 취소·회전·모달·차례 변경·Esc·포커스 이탈 시 드래그 취소, 합성 클릭 억제를 추가했습니다.
- PC의 유연한 탁 배치와 휴대폰 가로의 이름표 있는 버림패 열을 구현했습니다. SVG 패 문양, 공개 패 확대·같은 종류 강조, 독립 보조문자·추천·도라 표시 설정을 제공합니다.
- 리치 선언패를 90도 회전하고, 가져간 패도 원래 버림패 자리를 유지합니다. 규칙 엔진의 수락 이벤트에만 1,000점과 공탁봉 이동을 연결했습니다. 선언패 론 시 공탁금을 받지 않습니다.
- 좌측 상단에 왕패 14장 구조와 열린 도라 표시패를 표시합니다. 실제 도라는 별도 설정이며 CPU 손패와 미공개 우라도라는 표시하지 않습니다.
- 고정 여성 4명의 실제 기본 일러스트·7종 표정·승리 컷인·특수 포즈를 제작하고 대국·환영 화면·리치·화료·순위·대사에 연결했습니다. 등장인물·공격/수비/균형 성향과 난이도를 분리했습니다.
- 만관 이상을 캐릭터 등장→화료패→모든 역→최종 점수→점수 이동·순위 변화 순서로 연출합니다. 엔진 점수의 만관·하네만·배만·삼배만·역만 등급을 사용하고 다중 론을 순차 표시합니다. 건너뛰기와 미리보기에 중복 정산이나 대국 난수 변경이 없습니다.
- 효과음 WAV 7개를 제작했습니다. 음량·대사 빈도·대사 끄기·연출 길이·동작 줄이기를 지원합니다. 음성은 미제작으로 표시했습니다.
- 요청형·자동형·멈춰서 배우기 가이드와 첫 대국 안내를 추가했습니다. 역 없음·후리텐·리치 불가 이유와 공개 정보 기준의 미확인 패 수를 설명합니다.
- v3 저장 형식, 기존 키 보존 마이그레이션, 입력 검증, 저장 거부 대응, 배경 전환 시 입력·CPU 예약 취소와 복귀를 추가했습니다.
- 확장 경계를 정리하고 신규 모드 분리·리플레이·패보·전적 통계의 타입·데이터 예시는 문서로만 작성했습니다.
